# Flowers Dataset 🌼🌹🌻🌷🌺

This dataset contains images of flowers.\
It is organized into **5 categories**, with a **75/25% split** between
training and validation sets.

## Categories

-   Daisy
-   Dandelion
-   Rose
-   Sunflower
-   Tulip

## Structure

```
flowers_dataset/
├── train/ # 75% of images for training
│ ├── daisy/
│ ├── dandelion/
│ ├── rose/
│ ├── sunflower/
│ └── tulip/
├── test/ # 25% of images for validation
│ ├── daisy/
│ ├── dandelion/
│ ├── rose/
│ ├── sunflower/
│ └── tulip/
```

## Dataset size

The dataset is split **75% for training** and **25% for validation/testing**.  
Here are the counts per class:

| Class      | Train | Test | Total | Train % |
|------------|-------|------|-------|---------|
| Daffodil   | 121   | 41   | 162   | 74.7%   |
| Daisy      | 129   | 43   | 172   | 75.0%   |
| Rose       | 158   | 53   | 211   | 74.9%   |
| Sunflower  | 191   | 64   | 255   | 74.9%   |
| Tulip      | 123   | 41   | 164   | 75.0%   |
| **TOTAL**  | 722   | 242  | 964   | 75.0%   |
